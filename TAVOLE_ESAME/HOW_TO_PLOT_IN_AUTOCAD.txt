THE ARCTIC LENS — exam set
Seven boards 900 × 900 mm (90 × 90 cm)

FILE
  TAVOLE_ESAME_90x90.dxf
  Units = millimetres
  Open this file FROM this folder so AutoCAD finds assets\ images.

WHAT YOU SEE IN MODEL SPACE
  7 sheets side by side, 200 mm apart:
    TAVOLA 1  (0,0)
    TAVOLA 2  (1100,0)
    TAVOLA 3  (2200,0)
    TAVOLA 4  (3300,0)
    TAVOLA 5  (0,-1100)
    TAVOLA 6  (1100,-1100)
    TAVOLA 7  (2200,-1100)

PAPER SPACE
  Layouts TAVOLA_01 … TAVOLA_07
  Each layout is 900 × 900 mm with a 1:1 viewport of that sheet.

HOW TO PLOT (one board)
  1. Open the layout TAVOLA_01 (or 02…07)
  2. PLOT
  3. Printer: PDF or your plotter
  4. Paper size: custom 900 x 900 mm  (if missing: add it in PC3 / plotter)
  5. Plot area: Layout
  6. Scale: 1:1
  7. Plot with plot styles: NO  (true colour)
  8. Fit to paper: NO
  9. Centre plot: YES

IF THE LAYOUT VIEWPORT IS EMPTY
  In MODEL, zoom to the sheet, then
  PLOT → Window → pick the 900×900 frame → scale 1:1.

IMAGES
  Keep the folder  assets\  next to the DXF.
  If an image is missing: IMAGE command → reload path.
